# GoldVista Analytics Dashboard

## Project Overview

GoldVista Analytics is a Business Intelligence project developed to analyze jewellery sales, returns, customer behavior, branch performance, old-gold purchases, payment modes, and product performance.

The project transforms transactional data into an interactive Power BI dashboard to support business decision-making.

## Business Objectives

- Monitor overall sales revenue and sales performance
- Analyze branch and division performance
- Identify customer purchasing patterns
- Analyze product and karat performance
- Monitor return rates
- Analyze old-gold buy-back activity
- Understand payment mode trends
- Track important business KPIs

## Tools Used

- SQL / PostgreSQL – Data extraction, validation and analysis
- Power BI – Data modeling, DAX and dashboard development
- Excel – Data documentation and supporting analysis
- GitHub – Project version control and documentation

## Data Model

The project follows a star/snowflake-style analytical model containing:

- Fact Sales
- Fact Returns
- Fact Old Gold Purchase
- Fact Sales Payment
- Item Dimension
- Item Type Dimension
- Karat Dimension
- Payment Mode Dimension
- Date Dimension

## Key KPIs

- Total Revenue
- Total Weight Sold
- Return Rate
- Total Invoices
- Average Invoice Value
- Old Gold Buy-Back Volume
- Old Gold Buy-Back Value
- Repeat Purchase Rate
- Revenue per Customer
- Customer Lifetime Value
- Month-over-Month Revenue Growth

## Dashboard Pages

1. Executive Summary
2. Branch Performance
3. Customer Intelligence
4. Sales Deep Dive
5. Returns & Operations

## Key Findings

The dashboard helps identify:

- Revenue performance and monthly trends
- Top-performing branches
- Revenue contribution by division
- Dominant gold karat
- Customer repeat-purchase behavior
- Return patterns
- Old-gold buy-back contribution
- Payment mode distribution
